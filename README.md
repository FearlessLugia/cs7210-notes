# CS 7210: Distributed Computing

This repository contains the lecture transcripts for CS 7210: Distributed Computing (DC), a course offered by the
Georgia Institute of Technology (Georgia Tech).

## About These Notes

Thanks to GPT-6 Astra for organizing all of these notes.

1. **Obtain subtitles.** Export English subtitles from YouTube using `yt-dlp`. When English subtitles are unavailable,
   use AI speech recognition to transcribe the original audio.
2. **Format the transcript.** Remove individual subtitle timestamps, restore punctuation and capitalization, and group
   related sentences into paragraphs under numbered section headings. Preserve the original wording and explanations
   rather than summarizing them.
3. **Add the slides.** Render the course slides as images and insert each image before its corresponding transcript
   passage. Omit title-only pages and retain step-by-step diagrams. Use relative image links so the notes display
   directly on GitHub.

The lesson Markdown files are in the repository root. Slide images are in `slides/`.
